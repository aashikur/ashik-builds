## 1. Project Vision & Purpose

This website serves as the primary digital headquarters and client conversion platform for **Ashikur Rahaman** — Full-Stack Developer, UI/UX Crafter, and Digital Solutions Consultant.

### Primary Goal:
Transform visitors (founders, business owners, design agencies, and hiring managers) into inbound leads and long-term partners by presenting tangible, verified proof of competence:
1. **Live, usable web applications.**
2. **Interactive UI/UX Figma prototypes.**
3. **Genuine client video and written testimonials.**
4. **Transparent service offerings, pricing tiers, and direct consultation booking.**

## 3. Core Feature Deliverables (In-Scope)

### 3.1 Hero & First Impression
- **Headline & Value Proposition:** High-clarity positioning stating core competencies (Full-Stack, React, Node.js, UI/UX).
- **Interactive Developer Card:** Visual code editor preview (`coder.js`) demonstrating real-world technical identity.
- **Dual Conversion Triggers:**
  - `Explore Projects` (Smooth scroll to work showcase).
  - `Get in Touch / Book Call` (Direct contact gateway).
- **Resume Download:** Direct link to downloadable PDF resume.

### 3.2 Proof & Trust Engine (Social Proof)
- **Tech Stack Ticker:** Infinite animated marquee of trusted technologies and platforms.
- **Verified Client Reviews:** Testimonial grid with client avatar, company role, 5-star rating, and verification badges.
- **Video Testimonial Support:** Interactive trigger for client video feedback without compromising page load speeds.

### 3.3 Featured Work & Multi-Asset Case Studies
Every showcased project provides complete transparency with up to 4 asset triggers:
1. **Live Preview Link:** One-click launch to test the actual running application.
2. **Frontend & Backend Repositories:** Direct links to clean GitHub source code.
3. **Figma Design Link:** Link to the original design board demonstrating UX/UI craftsmanship.
4. **Video Walkthrough:** Short walkthrough or client review clip.

### 3.4 Services & Clear Pricing Framework
- **Tiered Packages:** Transparent packages for MVP development, landing pages, and full-stack web applications.
- **Deliverables Breakdown:** Clear listing of what is included in each tier (responsive layout, database, auth, SEO, deployment).
- **Direct WhatsApp / Inquiry CTA:** Frictionless path for custom project quotes.

### 3.5 Contact & Lead Generation
- **Integrated Contact Form:** Simple, distraction-free inquiry interface.
- **Direct Reach Channels:** Direct WhatsApp, Email, LinkedIn, and GitHub links.
- **Global Sticky Navigation:** Header with quick logo reset, theme toggle (Dark/Light mode), and bottom-to-top scroll trigger.

## 4. Scope Boundary (Locked vs. Out-of-Scope)

To maintain rapid delivery and bulletproof stability, clear boundaries are established:

### ✅ In-Scope (Phase 1 Baseline)
- High-performance Single Page Application (SPA) built on Vite, React 19, and Tailwind CSS v4.
- Fast, global edge deployment on Vercel with zero routing 404 errors.
- Fully responsive layout optimized for mobile, tablet, and ultra-wide desktops.
- Standardized JSON data models for instant project and review additions.
- Dark & Light mode theme support.

### 🚫 Out-of-Scope (Deferred to Future Phases)
- *Custom Headless CMS Backend:* All content is managed directly via Git-tracked JSON files (faster, zero monthly database cost).
- *Automated In-App Payment Checkout:* Inquiries and custom contracts are negotiated directly via WhatsApp or Email.
- *Real-Time In-App Chat:* Visitors connect directly via WhatsApp / Email.
